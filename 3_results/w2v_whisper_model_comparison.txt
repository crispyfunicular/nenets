KEY TAKEAWAYS
-------------

1. KhO data helps XLSR slightly (70.87% -> 68.42% WER).

2. The default Whisper export (best eval_loss = checkpoint-200) looks terrible
   (106% WER). The same run's checkpoint-1200 (best eval_wer) is much better
   (45.26% WER / 14.64% CER) and is currently the best system on this test.

3. Training validation = fixed test in this pipeline; document the selection
   criterion. Prefer a true train/dev/test split later.


BOTTOM LINE
-----------
Report Whisper checkpoint-1200 (WER selection) alongside XLSR. Do not conclude
that KhO broke Whisper based only on the best-loss export.
